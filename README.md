# Meu primeiro site

Página pessoal criada como exercício inicial de HTML, CSS e JavaScript, com visual inspirado em terminal e efeito de fundo em canvas.

## Acessar

[Ver a página publicada](https://dhonorio73.github.io/meu_primeiro_site/).

Para executar localmente, clone o repositório e abra `index.html` em um navegador. Não há dependências para instalar.

## O que o projeto demonstra

- Estruturação de conteúdo com HTML.
- Estilização com CSS e adaptação à largura da tela.
- Animação de fundo com JavaScript e canvas.

Este é um projeto de aprendizagem e representa uma etapa inicial do meu portfólio.
